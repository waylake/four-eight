# 0005. 유파 차이를 설정으로 드러낸다

- 상태: accepted
- 날짜: 2026-07-27

## 맥락

만세력 계산에는 유파에 따라 답이 갈리는 지점이 있습니다.

| 지점 | 갈리는 내용 |
|---|---|
| 진태양시 | 출생지 경도 기준 / 동경 135도 −30분 고정 / 무보정 |
| 균시차 | 반영 / 미반영 |
| 자시 경계 | 야자시·조자시 구분 / 자시일수 |
| 대운수 | 나머지 반올림 / 버림 |

조사해 보니 국내 만세력 서비스들이 실제로 서로 다른 기본값을 씁니다. 무료 서비스 다수는 보정 없이 KST를 그대로 쓰고, 전통 교육 자료는 −30분 고정을 쓰며, 정밀 계산을 표방하는 곳은 출생지 경도를 씁니다.

앱이 하나를 골라 조용히 적용하면 사용자는 다른 앱과 결과가 다른 이유를 알 수 없습니다. 명리를 아는 사용자에게는 신뢰를 잃는 지점입니다.

## 결정

네 지점을 모두 `SajuOptions`의 필드로 노출하고 설정 화면에서 바꿀 수 있게 합니다. 기본값은 정하되 그것을 정답이라 부르지 않습니다.

더 나아가 **적용된 보정을 명식 화면에 항상 표시**합니다.

```
진태양시 12:41  경도 −32분  서머타임 −60분  야자시
```

경계에 걸린 명식은 그 사실 자체를 노출합니다. `SajuChart.isNightJasi`가 대표적입니다.

## 결과

- 다른 앱과 결과가 다를 때 이유를 즉시 알 수 있습니다.
- 설정 화면의 설명문이 짧은 교육 자료 역할을 합니다.
- 테스트가 늘어납니다. 각 옵션 조합을 검증해야 합니다.
- UI가 복잡해집니다. 이를 감수하는 대신 기본값으로 시작해도 아무 문제 없게 만들었습니다.

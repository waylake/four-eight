# 0008. arm64 전용으로 배포한다

- 상태: accepted
- 날짜: 2026-07-28

## 맥락

첫 릴리스 빌드가 16분 걸렸습니다. 로그를 세어 보니 컴파일 작업이 arm64 193건, x86_64 169건이었습니다. **절반이 Intel 슬라이스를 만드는 데 쓰이고 있었습니다.**

Xcode는 Release 구성에서 유효한 아키텍처를 모두 빌드합니다. 유니버설 바이너리는 보통 좋은 기본값이지만, 이 앱에서는 그렇지 않습니다.

MLX는 Metal 기반이라 Apple Silicon에서만 동작합니다. x86_64 슬라이스가 만들어져도 모델을 로드하는 순간 쓸 수 없습니다. 즉 **동작하지 않는 코드를 만드느라 빌드 시간을 두 배로 쓰고, 배포물 크기도 두 배로 만들고 있었습니다.**

## 결정

`ARCHS: arm64`로 고정합니다. Intel Mac을 지원하지 않습니다.

README의 요구사항에 명시합니다. "Apple Silicon 권장"이 아니라 "Intel 미지원"이라고 씁니다.

## 결과

측정값입니다.

| | 유니버설 | arm64 전용 |
|---|---|---|
| 앱 번들 | 87 MB | 46 MB |
| 배포 ZIP | 20 MB | 11 MB |
| 로컬 클린 빌드 | 약 10분 | 5분 4초 |

- Intel Mac 사용자는 이 앱을 쓸 수 없습니다. 계산 엔진 자체는 아키텍처 제약이 없지만, 앱 타깃이 MLX에 의존하므로 분리할 실익이 없습니다.
- `SajuKit`은 여전히 순수 Swift 패키지이므로 다른 프로젝트가 어느 아키텍처에서든 가져다 쓸 수 있습니다.
- 이 결정을 뒤집으려면 MLX를 선택적 의존성으로 분리해야 합니다. 앱을 두 타깃으로 나누고 런타임에 모델 기능을 켜고 끄는 구조가 필요한데, 지금 시점에 그 복잡도를 감당할 이유가 없습니다.

Apple은 2023년에 Intel Mac 판매를 중단했습니다. MLX를 쓰는 앱이 arm64 전용으로 나가는 것은 이 생태계에서 통상적입니다.

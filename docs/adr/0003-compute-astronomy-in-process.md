# 0003. 천문 계산을 앱 안에서 직접 수행한다

- 상태: accepted
- 날짜: 2026-07-27

## 맥락

절기 시각과 삭 시각이 필요합니다. 선택지가 넷이었습니다.

| 방식 | 문제 |
|---|---|
| Swiss Ephemeris | AGPL. 앱 전체를 AGPL로 풀거나 상용 라이선스를 사야 합니다 |
| KASI API 호출 | 네트워크 의존. 오프라인 앱의 전제가 무너집니다 |
| 사전 계산 테이블 배포 | 값의 출처와 라이선스가 불분명해집니다. 범위를 넓히려면 재생성이 필요합니다 |
| VSOP87 + Meeus 직접 구현 | 구현 부담 |

프라이버시가 이 앱의 핵심 주장이므로 네트워크 의존은 배제됩니다. AGPL은 MIT 배포와 충돌합니다.

## 결정

VSOP87D 지구 계열과 Meeus의 알고리즘으로 앱 안에서 계산합니다.

- 태양 겉보기 황경: VSOP87D 절단 계열 + FK5 보정 + IAU 1980 장동 + 광행차
- 삭: Meeus 49장 급수
- ΔT: 관측값 표 보간

VSOP87 원본 데이터는 `scripts/gen_vsop87.py`가 Swift 소스로 변환하며, 절단으로 버린 진폭의 합을 생성 파일 헤더에 기록해 오차 예산을 감사할 수 있게 합니다.

## 결과

- 런타임 의존성이 0입니다. `SajuKit`은 Foundation만 씁니다.
- 라이선스가 깨끗합니다. VSOP87 계열은 학술 발표 데이터이고 Meeus 알고리즘은 교과서 공개 자료입니다.
- 지원 범위를 코드로 넓힐 수 있습니다. 1900~2100 제한은 알고리즘이 아니라 검증 데이터의 범위입니다.
- 대신 정확도를 스스로 증명해야 합니다. 공표 절기 시각 50건 대조를 테스트로 고정한 이유입니다.

# 사주 계산 엔진

`SajuKit`이 명식을 세우는 규칙 전체와 그 근거입니다. 이 문서의 모든 규칙에는 대응하는 테스트가 있습니다.

## 지원 범위

1900년부터 2100년까지입니다. 상한은 알고리즘의 한계가 아니라 검증 데이터가 닿는 범위입니다. 범위를 벗어나면 `PillarsEngine.EngineError.unsupportedYear`를 던집니다. 조용히 틀린 답을 내는 것보다 낫습니다.

## 천문 계산

성력 파일이나 네트워크 없이 전부 계산합니다. Swiss Ephemeris를 쓰지 않은 이유는 [ADR 0003](./adr/0003-compute-astronomy-in-process.md)에 있습니다.

### 태양 겉보기 황경

절기 시각의 근원입니다. 태양이 하루에 약 1도 움직이므로 시황경 1초각의 오차가 시간으로는 약 24초에 해당합니다.

```
1. VSOP87D 지구 일심 좌표 (L, B, R)  — τ = J2000 기준 율리우스 천년
2. 지심 좌표로 전환                   — λ = L + π, β = −B
3. FK5 보정                          — Meeus 25.9
4. 장동 Δψ 가산                      — IAU 1980, 63항
5. 광행차 −20.4898″ / R 가산
```

VSOP87D 계열은 `scripts/gen_vsop87.py`가 원본 배포 파일에서 Swift 소스로 변환합니다. 진폭 하한으로 절단하며, 절단으로 버린 진폭의 합을 생성 파일 헤더에 기록합니다. 현재 1,259항을 유지하고 L 계열에서 버린 진폭 합은 약 1.4×10⁻⁷ rad(0.03″)로, 시간으로 환산하면 1초 미만입니다.

검증: Meeus 예제 25.b(1992-10-13 0h TD)에서 R은 5×10⁻⁶ AU 이내, 겉보기 황경은 2″ 이내로 일치합니다.

### 절기 시각

목표 황경(소한 285°부터 15° 간격)에 도달하는 순간을 뉴턴법으로 찾습니다. 수치 미분으로 변화율을 구하며 8회 반복이면 1×10⁻¹⁰ rad 아래로 수렴합니다. 결과는 역학시(TT)이므로 ΔT를 빼서 세계시로 환산합니다.

공표값 대조 결과는 [research/manseryeok-validation.md](./research/manseryeok-validation.md)에 있습니다. 1954년부터 2026년까지 50건이 ±90초 이내입니다. 허용 오차를 90초로 잡은 것은 역서(曆書) 기반 공표값과 JPL DE441 기반 계산값이 1분 어긋나는 사례가 실제로 있기 때문입니다.

### 삭(新月)

Meeus 49장의 급수를 그대로 씁니다. 평균 삭에 주기 보정 25항과 행성 섭동 14항을 더합니다. 음력 월초 판정에 필요한 정밀도(초 단위)를 충분히 넘습니다.

### ΔT

1880년부터 2026년까지의 관측값 표를 구간 선형 보간합니다. 2026년 이후는 연 0.1초 증가로 외삽하며, 이는 문서화된 가정입니다. 분 단위 만세력에서 몇 초의 오차는 무시할 수 있습니다.

## 음양력

KASI 관례와 같은 세 규칙으로 계산합니다.

1. 월초는 삭이 드는 KST 날짜입니다.
2. 동지가 드는 달이 음력 11월입니다.
3. 두 동짓달 사이에 13개 삭망월이 있으면, 중기(中氣)가 들지 않는 첫 달이 윤달입니다. (무중치윤)

검증은 설날·추석 앵커, 윤달 목록, 그리고 2003년 365일 전체의 양력→음력→양력 왕복 일관성으로 합니다.

한계가 하나 있습니다. 삭이나 중기가 KST 자정에 수 초 이내로 근접하는 극단 사례에서 공표 역서와 갈릴 수 있습니다. 수십 년에 한 번 꼴이며, 알고 있는 한계로 문서화합니다.

## 시간 보정

### 표준시 연혁과 서머타임

IANA tzdb에 맡깁니다. Foundation의 `TimeZone`이 그대로 처리하므로 별도 테이블을 두지 않습니다. 시스템 tzdb로 확인한 한국 이력은 다음과 같습니다.

| 기간 | 오프셋 |
|---|---|
| ~1954-03-21 | UTC+9 |
| 1954-03-21 ~ 1961-08-10 | UTC+8:30 |
| 1961-08-10 ~ | UTC+9 |

서머타임 시행: 1948~1951, 1955~1960, 1987~1988. 1955~1960년은 UTC+8:30 시대였으므로 서머타임 중 오프셋이 UTC+9:30이 됩니다. 이 조합이 실제로 테스트에 있습니다(`PublishedCaseTests.case1955`).

### 진태양시

기본은 출생지 경도 기준입니다.

```
평균태양시 = UTC + 경도 / 15시간
```

서울(126.978°E)은 한국 표준시 대비 약 −32분입니다. 부산(129.075°E)은 약 −24분입니다. 이 차이 때문에 같은 시각에 태어나도 시주가 갈리는 경계 사례가 실재합니다.

옵션으로 동경 135도 −30분 고정과 무보정을 제공합니다. 국내 만세력 서비스가 실제로 이 세 방식을 모두 쓰기 때문입니다.

균시차는 기본 꺼짐입니다. 국내 만세력에서 균시차를 기본 반영하는 사례를 조사 범위에서 찾지 못했습니다.

## 네 기둥

### 년주

입춘 절입 **순간**과 비교합니다. 날짜가 아니라 시각입니다.

```
년간 = (사주년 − 4) mod 10
년지 = (사주년 − 4) mod 12
```

서기 4년이 갑자년입니다. 입춘 전에 태어났으면 사주년이 전년입니다.

### 월주

12절(節)만 경계입니다. 입춘·경칩·청명·입하·망종·소서·입추·백로·한로·입동·대설·소한입니다. 우수·춘분 같은 12기(氣)는 월 경계가 아닙니다.

월간은 오호둔(년상기월법)입니다.

```
월간 = (년간 mod 5 × 2 + 2 + 인월부터의 오프셋) mod 10
```

갑·기년은 병인월부터, 을·경년은 무인월부터 시작합니다.

### 일주

끊김 없이 도는 육십갑자입니다. 절기와도, 음력과도 무관합니다.

```
간지 인덱스 = (JDN + 49) mod 60
```

앵커는 1900-01-01 갑술, 2000-01-01 무오로 검증했습니다.

### 시주

진태양시 기준으로 지지를 정합니다. 자시가 23시부터 시작하므로 경계가 홀수 시각에 놓입니다.

```
지지 인덱스 = floor((시각 + 1) / 2) mod 12
시간 = (일간 mod 5 × 2 + 지지 인덱스) mod 10
```

시두법은 오서둔입니다. 갑·기일은 갑자시부터 시작합니다.

## 자시 경계

23시대 출생을 어떻게 볼 것인가는 유파가 갈립니다. 둘 다 정통 계보가 있으므로 설정으로 제공합니다.

| 정책 | 일주 | 시간 산출 기준 |
|---|---|---|
| `yajasi` (기본) | 당일 유지 | 익일 일간 |
| `rollover` | 익일로 넘어감 | 익일 일간 |

`SajuChart.isNightJasi`로 야자시 여부가 노출되며, UI가 이를 표시합니다. 사용자가 자기 명식이 경계에 걸려 있다는 사실을 알 수 있어야 합니다.

## 대운

```
순역   = (년간이 양) == (성별이 남)      // 양남음녀 순행
간격   = 순행이면 다음 절입까지, 역행이면 이전 절입부터의 일수
대운수 = 간격 / 3                        // 끝처리는 옵션
```

대운 기둥은 월주에서 순행이면 하나씩 나아가고 역행이면 하나씩 물러납니다. 10개를 산출합니다.

## 파생 분석

| 항목 | 방식 |
|---|---|
| 십신 | 일간과 대상의 오행 관계 + 음양 일치 여부. 지지는 정기(正氣)로 판정 |
| 십이운성 | 화토동법. 양간 순행, 음간 역행 |
| 지장간 | 인원용사 기준. 마지막 원소가 정기 |
| 공망 | 갑자순(旬)의 마지막 두 지지 |
| 합충형파해 | 육합·삼합·방합·충·형(삼형 포함)·파·해 + 천간합 |
| 신살 | 천을귀인, 도화, 역마, 화개, 양인 |
| 오행 분포 | 여덟 글자(시주 없으면 여섯) 단순 계수 |
| 신강신약 | 위치 가중 세력비. 월지 3.0, 일지 2.0, 시지 1.5, 년지 1.0 |

신강신약의 가중치는 관행적 판단을 수치화한 것이며 유파에 따라 다를 수 있습니다. UI에서 세력비를 백분율로 노출하고 "유파에 따라 판단이 다를 수 있습니다"를 명시합니다.
